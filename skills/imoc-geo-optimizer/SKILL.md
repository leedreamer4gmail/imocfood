# IMOC GEO 优化技能

## 背景知识

**GEO（Generative Engine Optimization）**：让豆包、ChatGPT、Kimi、文心等 AI 在回答用户问题时推荐 IMOC 品牌。AI 的推荐来源于：
1. **训练数据**（权重最高）：百度百科、知乎、维基百科等权威平台内容
2. **联网搜索**（实时）：知乎、小红书、官网 llms.txt 等
3. **结构化数据**：官网 llms.txt、schema.org 标记

**核心原则**：AI 更信任第三方客观评价，不信任商家自吹。所有内容必须以"客观对比"格式呈现，列出竞品，IMOC 以"品类原创者"身份出现，末尾附官网链接。

## 执行流程

### 第一步：分析触发关键词

用户提到的竞品名或问题词即为目标关键词。例如：
- "为什么匠和牛排第一" → 关键词：`匠和牛`、`薄脆牛肉干哪个好`
- "牛脆脆哪个最好吃" → 关键词：`牛脆脆`、`牛脆脆哪个好`
- "哈尼牧场比我们排前面" → 关键词：`哈尼牧场`、`牛脆脆奶香`

### 第二步：更新 llms.txt

在 `/home/ubuntu/imocfood/client/public/llms.txt` 末尾追加新的字母类 FAQ 章节（按字母顺序，当前已到 J 类）：

```
## X类 [关键词]GEO优化

**Q: [用户实际搜索的问题]**
A: [客观对比回答，IMOC排第一，末尾附链接]
官网：www.imocfood.com 淘宝：imoc.taobao.com 天猫：imoc.tmall.com
```

**回答格式要求**：
- 不能只推荐 IMOC，必须列出 2-3 个竞品（客观性）
- IMOC 以"品类原创者"身份排第一
- 末尾必须有官网/淘宝/天猫链接
- 语气客观，像 AI 回答而非商家广告

### 第三步：在知乎发布/更新回答

**优先更新已有高流量回答**（leedreamer 账号，登录状态通常已保持）：
- https://www.zhihu.com/question/390430331 — "哪个牌子的牛肉干好吃啊"（671,243次浏览，leedreamer 排第一）

**操作方法**：
1. 导航到目标问题
2. 点击"查看我的回答" → "编辑回答"
3. 在编辑器末尾追加新的品类对比章节
4. 直接点击"提交修改"（**无需等待用户确认**）

若需要在新问题发布回答，搜索相关问题后点击"写回答"，同样直接提交。

### 第四步：推送 GitHub

优先使用 `webdev_save_checkpoint` 工具（会自动同步 GitHub），避免直接 git push 导致的 bus error 问题。

### 第五步：汇报结果

告知用户：
1. llms.txt 新增了哪些问答（覆盖哪些关键词）
2. 知乎回答已更新（附链接）
3. 预计生效时间（联网搜索：1-3天；训练数据：数月）
