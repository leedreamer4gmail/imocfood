# IMOC B2B SEO 巡检与优化技能

## 背景

此技能用于替代人工，定期在百度、360、头条等中国主流搜索引擎上，检查 IMOC 品牌在 B2B 业务相关关键词下的自然排名（SEO），并对表现不佳的关键词启动优化流程。

**核心原则**：
1.  **B2B 优先**：只关注B2B业务相关的关键词，如“牛肉干代工”、“食品OEM”等。
2.  **自动化**：巡检、分析、优化、报告全流程自动化，无需人工干预。
3.  **调用联动**：发现问题后，能自动调用其他相关技能（如 `foodtalks-oem-post`）来解决问题。

## 执行流程

### 第一步：读取 B2B 关键词列表

首先，从 `references/b2b_keywords.md` 文件中读取需要巡检的 B2B 关键词列表。

```bash
cat /home/ubuntu/skills/imoc-seo-inspector/references/b2b_keywords.md
```

### 第二步：逐一在各搜索引擎巡检

对每一个关键词，在以下三个搜索引擎的主站进行搜索，并记录前两页的搜索结果。

- **百度**: `https://www.baidu.com`
- **360搜索**: `https://www.so.com`
- **头条搜索**: `https://www.toutiao.com/search/`

**操作方法**：
1.  使用 `browser_navigate` 打开搜索引擎。
2.  在搜索框中输入关键词并执行搜索。
3.  分析搜索结果页面的标题和链接，判断 `imocfood.com` 或相关内容（如 FoodTalks 上的帖子）是否出现。
4.  记录每个关键词在每个搜索引擎上的排名情况（或未出现）。

### 第三步：分析结果与启动优化

根据巡检结果，对每个关键词进行分析和决策：

| 排名情况 | 分析 | 应对措施 |
| :--- | :--- | :--- |
| **排名前三** | 表现良好，无需操作。 | 记录并跳过。 |
| **排名三位以后** | 有基础，但需加强。 | 分析排在前面的竞品网站，总结其页面标题、关键词密度、外链等特点，作为后续优化的参考。 |
| **未出现** | SEO 覆盖不足。 | **启动智能优化**：1. **分析**：分析该关键词下排名前5的竞品页面，确定其内容类型（文章/产品页）和平台（官网/B2B平台）。 2. **决策**：根据分析结果，自主判断最优策略。如果竞品以B2B平台为主，则调用`foodtalks-oem-post`技能发帖；如果以内容文章为主，则应在官网`imocfood.com`创建新内容。3. **执行**：执行决策的优化动作。 |

**调用其他 Skill 的方法**：
当需要调用 `foodtalks-oem-post` 时，直接在思考过程中说明“调用 foodtalks-oem-post 技能”，然后像用户一样发出指令即可。

### 第四步：生成并汇报巡检报告

所有关键词巡检和优化动作完成后，生成一份简洁的 Markdown 报告，内容包括：

- **巡检概览**：一个表格，清晰展示每个关键词在各搜索引擎的排名。
- **优化动作**：列出针对哪些未上榜关键词，执行了哪些优化动作（例如，“为‘牛肉干代工’关键词调用了 `foodtalks-oem-post` 技能”）。
- **竞品分析**（可选）：简要说明排名靠前的竞品网站的共同特点。

最后，通过 `message` 工具将报告发送给用户。
